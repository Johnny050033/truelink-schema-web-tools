# TrueLink Schema 擴充工具 UI／UX 規格

狀態：待實作，僅規格。不得把 wireframe 當成已有 UI。
既有 SaaS 的 `public/admin/brand-ci.html` 為品牌參考，讀取不等於搬入開源 repo。

## 工作入口

小 popup 只呈現目前網站摘要與兩個主要動作：
「檢查此頁」及「開啟我的 Schema」。完整編輯使用獨立分頁，避免 popup
關閉就失去輸入，也避免長表單被 380px 寬度限制。sidebar 屬可選增強，
不能讓 Firefox 或 Safari 因無相同 API 而無法使用核心功能。

```text
頂列：TrueLink 標誌 / 工具名稱 / 明亮、深色、自動 / 帳號
左欄：目前頁面 / 我的 Schema / 匯入與匯出 / 同步與設定
主區：文件清單 → 表單或 JSON-LD 編輯 → 結構問題與修正建議
側欄：來源 / 版本 / 本機儲存狀態 / 雲端狀態 / 公開狀態
```

手機改為可收合導覽；不依赖 hover、不把關鍵動作藏在橫向溢出區。

## 建立與編輯

1. 新手可選 Organization、Person、LocalBusiness 起手式，欄位有例子與
   來源說明，不自動捏造公司資料、資格、評論或信任分數。
2. 「目前頁面匯入」先列出找到的 JSON-LD 區塊、來源與截斷情況，使用者
   選擇後才建立草稿；不直接覆蓋既有文件。
3. 表單與 JSON-LD 檢視切換不得靜默丟棄尚不支援的屬性。
4. 本機存檔有明確收據與失敗訊息。同步失敗保留本機修訂，衝突可比較
   兩版本；不可假顯示「已儲存至雲端」。
5. 刪除需先呈現文件名稱及本機／雲端影響；批次匯入先預覽，不自動公開。

## 状態與文案契約

| 狀態 | 顯示 | 操作 |
|---|---|---|
| 本機稿 | 僅儲存在此瀏覽器，尚未同步 | 匯出／登入啟用同步 |
| 未登入 | 本機功能仍可用 | 開啟 TrueLink 登入或註冊，完成後回原工作 |
| 準備同步 | 即將上傳的文件、帳號、用途 | 明確確認／取消 |
| 同步中 | 此版本正在同步 | 可繼續編輯，區分新修訂 |
| 離線／錯誤 | 尚未同步，本機稿保留 | 重試／匯出，不重複收費 |
| 衝突 | 兩份修改不同，尚未覆蓋 | 比較／另存版本 |
| 雲端成功 | 私人草稿已同步；版本與時間 | 匯出／刪除／另行公開 |
| 公開確認 | 哪些資料將可被公開取得 | 單獨確認，不預先勾選 |
| 查證未知 | 本次未查／來源過期／無法連線 | 顯示原因與時間，不以綠燈替代 |

檢查結果不得寫「保證被 Google 收錄／AI 引用」「Schema 完整所以安全」
或「未認證所以是假網站」。未知狀態不計為 0 分或成功。

## 品牌與可用性

- 沿用經確認可分發的 TrueLink 官方標誌，不重新畫一個相似商標。
  正式標誌、合成 demo 與程式碼的授權分開。
- 對齊 CI 的深藍／綠／金及語意色 token；中性主畫布、有限強調色。
  不用霓虹漸層、發光大卡片、機器人或 emoji 作結構圖示。
- 自訂 SVG 圖示需統一線寬，搭配文字；不得從 CDN 載入圖示字型或 script。
- 淺色／深色／跟隨系統，涵蓋表單、JSON 編輯器、狀態、dialog 與 disabled
  樣式；不能只有外框換色。
- 主要按鈕至少 44px 高；鍵盤焦點清楚、表單有 label、錯誤與欄位關聯，
  status 用可讀文字與 aria-live。縮放 200%、375px 與大螢幕皆驗收。
- 第一畫面不等待認證 API 才可用；本機 UI 與網路查詢分開載入。
  量測冷／熱啟動；API 慢或逾時仍能看稿、匯出、存本機。

## 登入與資料輸出不能混淆

外掛不能透過改瀏覽器 cookie、讀現有 Firebase token 或關閉 MFA 來整合。
登入按鈕回到受控的 TrueLink 登入流程，保留安全 return destination；
帳號連結協定未完成前，按鈕只能稱「開啟網頁工具」，不能稱「已連接」。
不得把 Schema、access/refresh token 或個資放一般導頁 URL query／hash，
亦不得預設加入推薦碼。帳號連結需另外完成：每家商店發行 ID 對應的精確
callback allowlist、一次性 state、OIDC nonce（如適用）、authorization-code
及 PKCE（僅在既有 provider 支援且審核通過時）。不得假設 Firebase 既有
流程已可直接用任意 OAuth code exchange。

若標準授權流程在已註冊 callback 使用一次性 code，必須綁定 state／PKCE、
立即兌換、禁止記錄與轉送；它與在任意頁面 URL 放持續有效 token 不同。
不得接受任意 return URL 或網頁 postMessage 帶來的登入結果；驗證精確
origin、sender、nonce 與版本。測試重播、偽造回呼、取消、過期及換帳號。
短期憑證只給最小 scope，優先存記憶體／受控 session；長期憑證保存方案
尚未批准，不先寫 storage.local。登出清掉授權狀態與帳號快取，不丟棄
使用者未同步的本機編輯。登入不代表同意上傳所有草稿。

程式提供的 `createSandboxedEmbed` 只適用靜態安全呈現。未來 JSON-LD
匯出可能提供 script 包裝給使用者部署到自己的網站，兩者驗證器必須分離；
不能為了 Schema 匯出而放寬一般 embed 的 script 禁令。
